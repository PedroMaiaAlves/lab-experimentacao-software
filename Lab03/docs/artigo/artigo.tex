\begin{abstract}
  This study investigates delivery performance in popular open-source repositories
  that use GitHub Actions. Releases, commits, and workflow runs are adopted as
  explicit operational proxies for the four DORA metrics. The study also evaluates
  how alternative definitions affect repository classification. This document
  presents the research questions, hypotheses, collection protocol, and the frozen
  sample of 300 repositories. Three declared independent human assessments cover
  60 projects and 300 releases. The revised heuristic meets the F1 threshold of
  0.70 on that sample. Project types cover all 300 repositories: the remaining
  240 were individually reviewed after automatic pre-classification.
\end{abstract}

\begin{resumo}
  Este estudo investiga o desempenho de entrega em repositórios open-source populares
  que utilizam GitHub Actions. Releases, commits e execuções de workflows são adotados
  como proxies operacionais explícitos para as quatro métricas DORA. O estudo também
  avalia como definições alternativas afetam a classificação dos repositórios. Este
  documento apresenta as questões de pesquisa, hipóteses, protocolo de coleta e
  a amostra congelada de 300 repositórios. Três avaliações declaradas humanas e
  independentes cobrem 60 projetos e 300 releases. A heurística revisada atinge
  F1 de pelo menos 0,70 nessa amostra. Os tipos cobrem os 300 repositórios: os
  240 restantes passaram por revisão individual após pré-classificação automática.
\end{resumo}

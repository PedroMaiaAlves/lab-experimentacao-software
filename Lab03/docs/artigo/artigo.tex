\begin{abstract}
  We study DORA proxies in 300 open-source repositories using GitHub Actions,
  from October 2025 to September 2026. Median release frequency is 0.326 per week
  and recovery takes 3.20 hours. Delivery frequency correlates with release-based
  failures but not CI failures. Changing operational definitions reclassifies
  about 40\% of 269 comparable projects. The corrective-release ratio has a median
  of 37.3\%. These results describe GitHub artifacts, not observed production
  deployments or incidents. Frozen data, code, and executable notebooks support
  offline reproduction.
\end{abstract}

\begin{resumo}
  Estudamos proxies DORA em 300 repositórios open-source com GitHub Actions,
  entre outubro de 2025 e setembro de 2026. A frequência mediana é de
  \labAFreqMediana\ release por semana e a recuperação leva \labARecMediana~horas.
  Frequência associa-se às falhas por release, mas não às de CI. Mudar as definições
  reclassifica cerca de 40\% dos 269 projetos comparáveis. A proporção mediana de
  releases corretivas é \labCReworkMediana\%. Os resultados descrevem artefatos
  do GitHub, não implantações ou incidentes observados em produção. Dados congelados,
  código e notebooks executáveis permitem reprodução offline.
\end{resumo}
